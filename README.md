### 🧠 Artificial Intelligence, Machine Learning & Computer Vision

<details open>
<summary><b>🔮 AI Personality Predictor — NLP Text Classifier</b></summary>
<p>

* **Overview:** An end-to-end NLP and machine learning platform predicting Myers-Briggs (MBTI) personality types from unstructured natural language text and document uploads.
* **Methodology:** Text preprocessing via a specialized spaCy/NLTK pipeline (URL extraction, custom stop-word filtering, lemmatization), multi-output TF-IDF feature matrices, and scikit-learn classifiers with confidence score calibrations.

* **Tech Stack:** `Next.js 15` `FastAPI` `Python` `Scikit-Learn` `spaCy` `NLTK` `Plotly`

<summary><b>🏏 Cricket Best XI Optimization Engine</b></summary>
<p>

* **Overview:** Algorithmic team lineup optimizer forecasting fantasy match-day performance ratings and formulating mathematically optimal 11-player squads.
* **Methodology:** Trained Random Forest and XGBoost regressors on player historical metrics to forecast expected point yields, then applied **Integer Linear Programming (ILP / PuLP)** constraint solvers.
* **Constraints Solved:** Salary cap limits, mandatory role allocations (batsmen, bowlers, all-rounders, wicketkeepers), and country/club representation limits.
* **Tech Stack:** `Python` `Pandas` `NumPy` `Scikit-Learn` `XGBoost` `Linear Programming (PuLP)`

</p>
</details>

<details>
<summary><b>🛍️ E-Commerce Customer Segmentation & Behavioral Analytics</b></summary>
<p>

* **Overview:** Unsupervised customer intelligence engine segmenting e-commerce user bases using transactional purchase histories.
* **Methodology:** Computed RFM (Recency, Frequency, Monetary) vectors, executed K-Means clustering, and utilized Principal Component Analysis (PCA) for dimensionality reduction and 3D visual cluster profiling.
* **Business Impact:** Automated cohort tagging (VIPs, Churn Risks, High-Potential Shoppers) linked to customized retention campaigns.
* **Tech Stack:** `Python` `Pandas` `Scikit-Learn` `K-Means Clustering` `PCA` `Matplotlib` `Seaborn`

</p>
